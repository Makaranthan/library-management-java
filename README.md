# Library Management System (Java)

## Description
A simple CLI-based Library Management System using Object-Oriented Programming in Java. 
Users can add books and display all available books in the library.

## Features
- Add a new book with title and author
- Display all books in the library
- Menu-driven and user-friendly

## Technologies Used
- Java
- Object-Oriented Programming (Classes, Objects, Methods)
- ArrayList for dynamic book storage

## How to Run
1. Compile the Java file:javac LibraryManagement.java
2. Run the program:java LibraryManagement


## Learning Outcome
- Practiced OOP concepts like classes and objects
- Learned to manage dynamic data using ArrayList
- Improved understanding of basic Java programming structure
